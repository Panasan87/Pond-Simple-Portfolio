# Portfolio Website Development Plan: Panasan Pond

## Project Overview
Goal: Build a professional, modern, dark-themed portfolio website as a Data Analyst.
Deployment Platform: GitHub Pages.

## Phase 1: Local Development
1. **Structure:** Create a project folder `panasan-pond-portfolio` with:
   - `index.html` (Main structure)
   - `style.css` (Dark theme, JetBrains Mono font)
   - `script.js` (Optional interactivity)
2. **Design Specifications:**
   - **Theme:** Modern Dark (Slate/Charcoal background, high-contrast accents).
   - **Typography:** JetBrains Mono (Google Fonts).
   - **Content:**
     - **Hero:** "Panasan Pond" | Data Analyst.
     - **Projects:** 3 highlighted data analysis projects.
     - **Contact:** Links to professional profiles/email.

## Phase 2: Repository Setup
1. **Initialize:** `git init`.
2. **GitHub:** Create a repository named `panasan-pond.github.io`.
3. **Push:** Link local repo to GitHub and push files.

## Phase 3: Deployment
1. **GitHub Pages:**
   - Go to **Settings > Pages**.
   - Select **Deploy from a branch** (`main` / `root`).
2. **Verify:** Check `https://panasan-pond.github.io` once build completes.
