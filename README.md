# Pond-Simple-Portfolio

A professional, modern, dark-themed portfolio website for **Panasan Pond**, a Data Analyst.

## 🚀 Project Overview
This project is a clean and efficient portfolio designed to showcase data analysis projects and professional skills. It features a modern dark theme and a focus on readability and performance.

## ✨ Features
- **Modern Dark Theme:** Styled with Slate and Charcoal colors for a professional look.
- **Typography:** Uses JetBrains Mono for a clean, developer-friendly aesthetic.
- **Responsive Design:** Optimized for various screen sizes.
- **Project Showcases:** Highlights key data analysis work.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling and layout.
- **JavaScript:** Minimal interactivity.
- **GitHub Pages:** Hosting and deployment.

## 📂 Project Structure
- `index.html`: Main entry point and site structure.
- `style.css`: Custom styling and theme definitions.
- `script.js`: Client-side logic and interactivity.
- `plan/`: Project development documentation and roadmap.
